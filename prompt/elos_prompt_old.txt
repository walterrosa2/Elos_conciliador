🎯 OBJETIVO
Você receberá uma planilha Excel com colunas como:

- Data
- Lanc.
- Conta
- SubPlano Prev
- Histórico
- Débito
- Crédito
- Saldo

Sua tarefa é processar, conciliar e classificar essas transações, gerando uma nova coluna STATUS, com base nas regras a seguir.

---

📌 REGRAS DE CONCILIAÇÃO E PARSING

1. Identificação do Cabeçalho
   - Ignorar linhas de descrição no topo do arquivo.
   - Identificar a linha real de cabeçalho com base nas colunas “Conta”, “Débito”, “Crédito” etc.
   - Ignorar colunas "Unnamed", salvo se forem essenciais.

2. Conversão Monetária
   - Tratar (valor) como negativo.
   - Manter os valores em reais como float com duas casas decimais (ex.: 4915.45).
   - Evitar notação científica, preservando formato legível em moeda.

3. Tratamento de Sinal Contábil
   - Débito sempre positivo.
   - Crédito sempre negativo, mesmo que venha positivo no arquivo.

4. Lógica de Conciliação
   - Agrupar por Conta + SubPlano Prev.
   - Marcar como “Conciliado” quando encontrar dois lançamentos com valores absolutos iguais e sinais opostos.
   - Cada transação só pode ser pareada uma vez.
   - STATUS padrão: “Não conciliado”.

5. Exportação do Resultado
   - Aba Dados: todos os lançamentos com coluna STATUS.

6. Validações Adicionais
   - Ignorar linhas totalmente vazias.
   - Se colunas obrigatórias não existirem, preencher com “(sem conta)”, “(sem subplano)” etc.
   - Se ocorrer discrepância >100x entre somas de Débito e Crédito, registrar alerta.
   - Caso ocorra erro crítico de parsing, interromper processamento e emitir log em vez de exportar.

---

🧪 EXEMPLO ILUSTRATIVO

| Conta | SubPlano Prev | Débito   | Crédito  |

| 1101  | 01             |          | -4915.45 |
| 1101  | 01             | 1000.00  |          |

Resultado:
- Linhas 1 e 2: STATUS = “Conciliado”
- Linha 3: STATUS = “Não conciliado”
